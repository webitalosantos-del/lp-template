# Template de landing page (HTML puro)

## Como criar uma página nova
1. Neste repositório template, clique em **Use this template → Create a new repository**.
   Nome do novo repositório: `lp-<cliente>-<slug>`.
2. Preencha o `briefing.md`.
3. Peça a página à IA (prompt padrão), que escreve tudo dentro de `site/`.
4. Ao enviar para a branch `main`, a aba **Actions** gera o pacote automaticamente.
5. Baixe o artefato (arquivo ZIP) e envie em **WordPress → Lovable Pages** com status Preview.
6. Aprovou? Clique em **Publicar** na lista de páginas.

O artefato baixado já é o ZIP certo: o `index.html` fica na raiz.
